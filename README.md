# Responsive Card Layout

A clean and simple 3-card responsive layout built using pure HTML5 and CSS3 (Flexbox).

## 📌 Features
- **Clean Structure:** Simple HTML5 elements without extra complexity.
- **Flexbox Alignment:** Equal alignment and responsive spacing using CSS Flexbox.
- **Custom Styling:** Rounded borders, clean background colors, and action buttons.

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
